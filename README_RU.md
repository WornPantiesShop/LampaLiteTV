# Lampa Lite TV 1.5.6-c645

Android TV WebView-оболочка Lampa для TCL C645 (Android 11, около 2 ГБ RAM).
Пакет `com.example.lampalitetv`; оригинальную Lampa и системные настройки ТВ не меняет.

## Меню и каталог (1.5.5)

По запросу пользователя убраны пункты «Настройки» и Shots/Shorts из бокового меню,
настройки оболочки по долгому BACK. В версии 1.5.6 шестерёнка настроек
в верхней панели восстановлена по запросу пользователя.
Существующие сохранённые настройки остаются на месте; внутренние механизмы настроек
Lampa сохранены для совместимости расширений. Это изменение интерфейса, не блокировка доступа.

Пункт «Русские» открывает выбор фильмов и сериалов.
Оба списка используют TMDB Discover с `with_original_language=ru` и сортировкой
по популярности: это русскоязычный контент, включая советские фильмы.
Ряды главной, анимации и параметры воспроизведения не меняются.

## Расширения и иконка (1.5.4)

При первом запуске этой версии через штатный менеджер Lampa добавляются и включаются:

- `https://modss.tv` — MODS's;
- `http://bwa.ad/rc`;
- `https://gpbx.me/w`.

Существующий список объединяется без дубликатов; остальные расширения сохраняются.
Маркер `lampa_lite_extensions_seed_v1` предотвращает повторную установку: если позже
отключить или удалить расширение в настройках Lampa, приложение не вернёт его автоматически.
Код расширений загружается с указанных серверов; их доступность и поведение зависят от авторов.
В APK добавлены адаптивная иконка с лампой/Play и подписанный баннер Android TV.
Проверка логики установки: `node tools/test-default-extensions.mjs` (Node.js 22+).
[Результаты проверки 1.5.4](docs/c645-extensions-2026-10-26.md): с тремя расширениями
повторный замер дал 51,8 FPS против 57,7 FPS до подключения. Постоянные 60 FPS не гарантируются.

## Что изменено

Версия 1.5.3 переносит цветовую анимацию Halloween-пламени логотипа на композицию
двух слоёв через прозрачность. Сохранены исходные цвета, easing, период 5 секунд и фаза.
Это убирает непрерывную перерисовку каталога из-за маленького логотипа.
Скрипт включается только на lampa.mx при точном совпадении проверяемых параметров
исходной анимации. Если она изменится, остаётся исходное поведение.

Анимации карточек, размеры, ряды, пульт, медиаплеер и DOM Storage не изменены.
Сохранена оптимизация фоновых таймеров из 1.5.2; данные при обновлении не очищаются.
На TCL C645 горизонтальная навигация выросла с 45,0 до 57,3–58,7 FPS.
**Постоянные 60 FPS пока не достигнуты**, особенно при переходах между рядами.

Новые измерения: [docs/c645-logo-compositor-2026-10-26.md](docs/c645-logo-compositor-2026-10-26.md).
Предыдущая оптимизация фона: [docs/c645-performance-2026-10-26.md](docs/c645-performance-2026-10-26.md).

## Сборка

Нужны JDK 17, Gradle 8.7 и Android SDK Platform 35. Можно открыть проект в Android Studio.
Gradle Wrapper JAR и запускные файлы в исходном проекте отсутствуют; для CLI нужен установленный Gradle.

```powershell
$env:ANDROID_HOME = "$env:LOCALAPPDATA\Android\Sdk"
gradle --no-daemon :app:assembleDebug :app:lintDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`.
Сохранён существующий `targetSdk 28`: миграция API не входит в эту оптимизацию.
Предупреждение lint о требованиях Google Play остаётся предупреждением для sideload-сборки;
эта настройка не делает приложение соответствующим требованиям публикации Google Play.

## Обновление телевизора без удаления данных

Используйте **существующий debug-ключ компьютера**. Ключ никогда не публикуется в Git.

```powershell
.\install-tv.ps1 -ApkPath .\app\build\outputs\apk\debug\app-debug.apk
```

Без `-ApkPath` скрипт сохраняет прежний режим: скачивает APK development-релиза GitHub.
В обоих случаях APK подписывается локальным ключом, проверяется и устанавливается только через `adb install -r`.
При несовместимости подписи установка останавливается; приложение не удаляется.
Для изолированных сред есть `-SdkPath`, `-KeystorePath`, `-WorkDirectory`.

BACK сохраняет единственную обработку через оболочку; настройки по удержанию удалены.

## Воспроизводимые измерения

Откройте главный каталог, дождитесь загрузки и установите фокус на **первую карточку первого ряда**.
Для каждого сравнения используйте одинаковый источник, настройки, прогрев и версию WebView.
Не нажимайте пульт во время автоматического сценария.

```powershell
py -3 .\tools\measure-c645.py `
  --adb "$env:LOCALAPPDATA\Android\Sdk\platform-tools\adb.exe" `
  --output .\diagnostics\before
```

Инструмент запускает `benchmark-c645.ps1` и `diagnose-c645.ps1`, затем одну и ту же последовательность
18 команд D-pad (4 вправо, 4 влево, вниз, 4 вправо, 4 влево, вверх). Сохраняются команды и время их выполнения.
Окно телеметрии — 30 секунд; выполнение всей последовательности на слабом ТВ может занять дольше.
После изменения повторите с `--output .\diagnostics\after` из той же начальной позиции.

Отдельные ручные захваты:

```powershell
.\benchmark-c645.ps1 -Seconds 30 -OutputPath .\diagnostics\presentation-times.txt
.\diagnose-c645.ps1 -Seconds 30 -OutputDirectory .\diagnostics
```

Оба скрипта принимают `-Device` и `-AdbPath`. Benchmark читает реальный период обновления,
сохраняет исходные timestamps и JSON. Диагностика дополнительно сохраняет версию WebView и ограниченный logcat.
Средний presentation FPS включает неподвижные интервалы, а gaps не равнозначны WebView jank.
`dumpsys meminfo` пакета показывает процесс оболочки, не всю память отдельного renderer.

## Ограничения

Контент и плагины загружаются с `http://lampa.mx`; доступность серверов и внешних плееров зависит от сети и настроек Lampa.
HTTP не защищён TLS. Проверка локального H.264-видео не гарантирует доступность каждого стороннего источника.
Библиотеки Chromium, принудительные GPU-слои, системные параметры ТВ и глобальные CSS-анимации не изменяются. Локальная оптимизация касается только проверенного пламени логотипа.
