# Lampa Lite TV 1.5.4: extensions and launcher artwork

Added and enabled the three user-requested URLs through Lampa.Plugins:

- https://modss.tv (MODS's)
- http://bwa.ad/rc
- https://gpbx.me/w

The one-time bootstrap waits for Lampa's app-ready event, merges the current list,
enables matching entries and avoids duplicates (including a trailing slash).
It saves lampa_lite_extensions_seed_v1 only after registration succeeds. Later
manual removal/disable is respected on subsequent launches. It does not bundle
third-party code, change catalog CSS, intercept remote keys or change system settings.
Remote code and its own settings remain controlled by the extension authors.

The APK now has an adaptive lamp/Play icon, a matching legacy icon and a labeled
320x180 Android TV banner. Its tile was visually verified on Google TV on TCL C645.
VersionCode 10; installed with install-tv.ps1, the existing local debug key and
adb install -r. No data clear, uninstall, TV reboot or system settings change.

## Performance observation

Both benchmark-c645.ps1 and diagnose-c645.ps1 were used via the same 24-key
horizontal native-input scenario and 400 ms post-key presentation windows.
Before: 57.71 FPS, p95 17.51 ms, intervals >25ms: 21/531.
After, valid repeat: 51.79 FPS, p95 33.39 ms, intervals >25ms: 71/472.
The first post-install run was excluded: it contained an extra arrow event and
ended in the menu, so it was not the same navigation scenario.

These are short observations, not a randomized causal experiment: server-loaded
Lampa version, warm caches, catalog contents and third-party work can differ.
The extension-enabled configuration was slower in this test; it must not be
advertised as fixed 60 FPS. All three extensions stay enabled as explicitly
requested. The startup bootstrap stops polling once Lampa is available and does
not create a permanent rendering loop.

Raw captures, storage snapshots, local keys and signed APKs are kept outside Git.
