# Lampa Lite TV 1.5.5: simplified menu and Russian catalog

The native settings dialog and its long-BACK gesture were removed. Existing
preferences remain stored. The native BACK dispatcher retains a single action
on key-up to avoid WebView + Activity double handling; fullscreen/back behavior
otherwise stays on the previous host path.

The page asset removes sidebar Settings and Shots/Shorts entries and the header
settings button, including entries added late by extensions. It observes only
the menu/header subtrees and their immediate replacement, not catalog animation
attributes. Internal settings APIs remain for extension compatibility; this is
UI customization, not an access-control/security feature. No global motion CSS,
row deletion, app-data clear, TV reboot or system settings changes.

The Russian menu entry uses the regular Lampa Select controller to choose movies
or TV series. Both open TMDB category_full, page 1, filtered by
with_original_language=ru and sorted by popularity.desc. This means Russian-
language titles, including Soviet films, not an exclusive production-country filter.
The previous three extensions, logo optimization and launcher artwork remain.
