# Возврат позиции из Vimu: 28.10.2026

Lampa Lite TV 1.5.15-c645 (21), Vimu 11.01, TCL C645 / Android 11.
Обновление install-tv.ps1 через install -r с прежним debug-ключом, без очистки данных.

Использован [официальный Vimu Player API](https://vimu.tv/player-api/):
startActivityForResult, startfrom (миллисекунды), forcename, forceresume=false.
Результаты position/duration переводятся из миллисекунд в секунды Timeline Lampa;
код 1 означает завершение, код 0 с корректными числами — остановку. Ошибки, отмена
chooser без результата и некорректные числа не меняют прогресс.

Нативная сессия содержит только непрозрачный ID и метаданные Timeline. Результаты
пишутся в ограниченную очередь до подтверждения сохранения JS. Стримы, токены и
учётные данные не сохраняются. Применение к другому активному профилю блокируется.
Режим выбора плеера пользователя остался ask.

## Реальная проверка на телевизоре

Для теста использован общедоступный ролик Pixabay №132279 (59.413 с) с отдельным
тестовым hash, без изменения отметок реальных фильмов:

1. Lampa → Android chooser → Vimu → штатный выход: positionMs=10481,
   durationMs=59413. Native подтвердил получение и сохранение в Lampa.
2. Timeline прочитан: time=10, duration=59, percent=18. Появились два пункта:
   «Продолжить с 00:00:10», «С начала»; скриншот сохранён вне репозитория.
3. Продолжение отправило startfrom=10000. Журнал Vimu подтвердил seek к 10 с;
   следующий выход вернул 44616 мс, прогресс снова обновился.
4. «С начала» открыл тот же ролик с нуля. На фоне Vimu процесс Lampa выгружен
   через am kill (без force-stop и очистки данных). Выход Vimu создал новый процесс
   Lampa; получены 8515 мс, Timeline затем прочитан как time=9. Это проверка
   восстановления результата после смерти процесса оболочки.
5. Удалена только созданная в тесте запись Timeline. Каталог доступен, 4 загруженных
   ряда. Пользовательские истории и настройки сохранены.

Сборка assembleDebug, синтаксические/логические проверки player-selection и resume
пройдены. Тесты покрывают единицы измерения, смену временной ссылки, разные серии,
выбор продолжить/сначала, завершение, некорректные результаты и изоляцию профилей.
Реальное завершение полного фильма и все сторонние плееры не проверялись.

Настройки Vimu (включая выбранный ранее рабочий движок) и системные настройки ТВ
в этой задаче не менялись. Новых анимаций, CSS-ограничений и фонового сервиса нет.
