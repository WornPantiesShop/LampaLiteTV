# Хэллоуин — за стеклом

Отдельная Android TV заставка (DreamService), пакет `com.example.hauntedscreen`.
Lampa и её данные не меняются. Интернет, специальные возможности, доступ к файлам
других приложений и системные разрешения записи настроек не требуются.

Видео выбраны пользователем:

- [Zombies](https://motionbgs.com/zombies): HEVC 3840×2160, 30 fps, 46.13 с.
- [Ghosts in the Wall](https://motionbgs.com/ghosts-in-the-wall): H.264 1920×1080,
  30 fps, 22.20 с.

Оригинальные MP4 сохраняются локально и исключены из Git. Для личной сборки с настроенным Android SDK, JDK 17+ и Gradle 8:

```powershell
powershell -File halloween-screensaver/get-wallpapers.ps1
gradle :halloween-screensaver:assembleDebug
```

Скрипт скачивает видео по опубликованным ссылкам и проверяет SHA-256. Исходники
приложения не дают прав на распространение чужих роликов. APK с ними в Git не
публикуется. `verifyWallpapers` не допускает сборку без локальных файлов.

Откройте приложение «Хэллоуин — за стеклом». Доступны предпросмотр и две кнопки ручного выбора видео. Звуковые эффекты полностью отсутствуют, громкость
MediaPlayer принудительно равна нулю. Выбранный ролик запоминается и зацикливается; автоматического чередования нет.
Видео декодируются штатным аппаратным декодером. Никакой форсированной отрисовки
60 кадров и WebView нет; исходники видео имеют 30 fps.

Для автоматического запуска нажмите «Выбрать заставку телевизора» и выберите
«Хэллоуин — за стеклом» в системном списке. Приложение само не меняет выбранную
заставку, тайм-аут, яркость или громкость телевизора. Возврат к стандартной заставке
выполняется через тот же список.

Кнопка пульта закрывает предпросмотр, громкость остаётся доступна. При уходе в фон
проигрыватель освобождается. Завершение DreamService также освобождает видео.

Интеграция использует [Android DreamService](https://developer.android.com/reference/android/service/dreams/DreamService).

На TCL C645 по прямому запросу владельца установлены выбор этой заставки и
тайм-аут бездействия 300000 мс (5 минут). Таймер сна 14339000 мс сохранён.
Текущий ролик меняется двумя кнопками в приложении; галочка отмечает выбор.
Стандартное значение по умолчанию — Ghosts in the Wall.

Проверка: обе кнопки выбора и предпросмотры выполнены с пульта, декодер
OMX.realtek.video.decoder; для 4K HEVC 137 кадров / 0 пропущено, для Full HD H.264
136 / 0 в коротких контрольных отрезках. Зацикливание включено, громкость обоих
каналов равна нулю. Пользователь подтвердил видео на физическом экране; ADB
снимок аппаратного видеослоя чёрный. Проверка полной длительности всех циклов
не выполнялась.

Системный запуск DreamManager проверен отдельно от предпросмотра: активна
GhostDreamService, mBound=true, Full HD H.264 158 кадров / 0 пропусков,
зацикливание включено, громкость 0/0. BACK завершает заставку и освобождает
проигрыватель. Тайм-аут 300000 мс считан обратно из настроек и PowerManager;
полное ожидание пяти минут для проверки таймера не выполнялось.

## Особенность автозапуска TCL C645

При запуске из закрытого состояния TCL App Boot Manager может блокировать
привязку DreamService, даже если она уже выбрана в системных настройках.
Признак в logcat: `callee_does't_have_OP_AUTO_START_permission`,
`Unable to bind dream service`, `reason='bindService failed'`.
Проверка сразу после открытия приложения не выявляет эту блокировку.

На телевизоре владельца, в рамках запрошенного автоматического запуска через
5 минут, разрешена только операция автозапуска нашего пакета:

```text
adb shell cmd appops set --user 0 com.example.hauntedscreen APP_AUTO_START allow
```

Прежнее значение было ignore. Данные приложения и разрешения других пакетов не
менялись. После исправления выполнен автоматический запуск без открытия Activity:
до запуска процесса не было, затем система сама запустила GhostDreamService
(mBound=true, mIsTest=false) на отметке 300 секунд бездействия. При чтении на
316.8 секунды воспроизводился Zombies HEVC 3840×2160, looping=true, громкость 0/0,
490 кадров / 0 пропусков. APP_AUTO_START: allow с зарегистрированным использованием.
